# TinyX 0.2.1 顶部标签栏滚动

首页标签栏取消吸顶，随时间线自然移出视口，回到页面顶部后重新显示。原生点击、横向切换和页面布局高度保留。

实现仅标记首页首个标签栏独立的 sticky 祖先，将其恢复为 relative 定位；不改虚拟单元、标签高度或滚动位置，不增加滚动监听或轮询。推文内标签、附件标签、弹窗和完整网页模式不应用该规则。

## 验证

- JavaScript 单文件语法与 14 项回归通过，包括嵌套 sticky、模式与路由切换、DOM 替换以及推文 / 附件 / 弹窗标签保护。
- 离线 fixture 使用真实 sticky 容器，已通过初始可见、下滚 680 px 后完全移出视口、回顶恢复检查；推文仍可见，虚拟单元几何不变。
- 已登录页面真实 Chromium 滚轮检查通过：第一次滚动后标签离开视口，累计滚动 4740 px 时标签 y 为 -4740 px，回到 scrollY=0 后重新可见；滚动样本均有可见推文。原始几何报告留在本地 work/，不收集推文正文或 Cookie。
- 实际首页标签的 sticky 祖先从 1 个变为 0 个；完整模式保留网站自身的 sticky 行为。
