# TinyX 0.2.0 页面优化与验证

## 本次修改

| 用户反馈 | 实现 |
| --- | --- |
| 托盘图标 | 深蓝小窗、白色 X、薄荷绿左下角；提供 SVG、八种尺寸 ICO 与可重现生成脚本，窗口和托盘共用图标 |
| 隐藏首页发帖区 | 支持当前 X 深层富文本结构，沿祖先最多查找 40 层；保留推文内回复、弹窗和首页标签 |
| 两个纵向滚动条 | 移除 body 的 overflow-x:hidden 和泛化 main > div 样式；保持 document 为主滚动容器，不改标签、弹窗或导航内部滚动 |
| 持续滚动出现空白 | 不改变 X 虚拟单元的高度、定位与 transform；主页面滚动始终同步到 html/window，避免增加独立 body 滚动 |
| 顶部标签、左侧导航 | 保留原生首页标签；按最新要求取消左侧悬停，精简模式隐藏左侧导航且无触发条；完整导航可通过托盘关闭精简模式恢复 |

实际页面中，发布按钮直到编辑器上方第 21 层才出现，原查找上限为 8。编辑器内部还有附件 tablist，因此保护规则改为只保护首页标签栏，不再把所有 tablist 都视为发帖区边界。

旧版 body overflow-x:hidden 是嵌套滚动风险项，不能仅靠这个声明认定现场空白的唯一原因。此次去除该规则，并以实际滚轮、滚动位置与可见推文数量验证修改结果。CSS 溢出轴计算规则见 [W3C CSS Overflow](https://www.w3.org/TR/css-overflow-3/#overflow-properties)。

## 主要代码位置

- `src/TinyX/Assets/content.js`：`markHomeComposer`、`markContentWrappers`、滚动根与模态状态处理。
- `src/TinyX/Assets/content.css`：主滚动容器、侧栏隐藏、发帖区隐藏。
- `src/TinyX/MainForm.cs`：嵌入图标、只读诊断、实际滚轮验证。
- `src/TinyX/PageDiagnostics.cs`：仅导出固定 DOM 标记、样式、尺寸和数量，不收集正文、Cookie、输入值或完整网址。
- `scripts/generate-icon.ps1`：SVG 与多尺寸 ICO 生成。
